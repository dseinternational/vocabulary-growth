# One-off experiment scripts

> [!NOTE]
> Revised with assistance from OpenAI Codex/GPT-6 on 2026-09-17.

These scripts preserve how specific exploratory results were obtained. They are not a common command-line interface. Read the script and its dated note before running it. Some require local path changes, old fits or assumptions that later work replaced. Results in the linked notes describe those runs, not the current model definitions.

Use a separate output root for experimental fits. Do not let an experiment replace a model of record. Prefer the supported sensitivity or recovery commands in `scripts/` when they cover the question.

Several experiments temporarily replace definitions before importing a model. New maintained variants belong in the sensitivity registry. A new definition field also needs a fit-identity classification and, where justified, a tested backward-compatibility default. See the [model inventory](../../docs/models/README.md).

Experimental scripts are outside the general trace-consumer coverage check. A script used to support a current claim must validate the definition and prepared data through `vocab_growth.fit_consumers`. Check its test coverage separately; placement here does not establish whether it has tests.

## Run an experiment

```bash
uv run python scripts/experiments/clamp_arm.py clamped --output-dir /scratch/throwaway
```

Check the path constants before using `compare_arms.py` or `verify_geometry.py`.

`psi_hierarchy_simulation.py` takes `--output-dir` and needs no stored trace. It fits a reduced version of VG15's association block, using approximations to the per-study likelihoods. It does not replace recovery of the full model. Its `--verify` option compares the closed-form calculation with a PyMC fit of the same reduced model.
